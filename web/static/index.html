Welcome to the mAIstr0 Orchestrator

The orchestrator plans and reasons visibly, then spreads LLM workloads across worker nodes while preserving every node response.

  • Dynamic Workload Balancing: LLM queries and subtasks are routed to the least-loaded nodes.
  • Parallel Multi-Node Dispatch: Subtasks can be executed simultaneously across distinct cluster nodes.
  • Interactive ReAct Loop: Real-time streaming of thoughts, tool calls, and node execution metrics.

Get your cluster ready

Check node connectivity, configured inference engines, and available models.

  1. Pair nodes securely. Copy the one-use PIN shown by the orchestrator and enter it on each node.
  2. Connect an engine. Nodes detect local Ollama and FastFlowLM services. Configure another engine from the node's settings.
  3. Load models. Refresh the model registry, then use a node's settings to choose its default model.
