# Security policy

## Reporting a vulnerability

Please do not report suspected vulnerabilities in a public issue. Use
[GitHub's private vulnerability reporting for this repository](https://github.com/dbhaigh/mAIstr0/security/advisories/new).
Include the affected version or commit, impact, reproduction details, and any
suggested mitigation. Do not include real prompts, API keys, pairing PINs,
private keys, or other user data in a report.

If private vulnerability reporting is unavailable, contact the repository
maintainers through GitHub and request a private reporting channel before
publishing technical details.

We will acknowledge reports and coordinate a fix and disclosure timeline with
the reporter. Please allow maintainers a reasonable opportunity to investigate
and release a fix before public disclosure.

For the runtime trust boundary, pairing, certificate lifecycle, and local
dashboard protections, see [Pairing and security](./docs/pairing-and-security.md).
